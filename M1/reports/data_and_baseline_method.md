# Method Section: Data and Baseline Engineering

## Data and Baseline

The data ingestion pipeline ingests daily campaign performance records and maps arbitrary column naming aliases (`spend`, `conversions`, `date`, `campaignid`) to a canonical schema (`campaign_id`, `campaign_name`, `cost`, `conv`, `day`, `impressions`, `clicks`, `revenue`). Input validation enforces non-negative counts and expenditures, parses ISO-formatted calendar dates, verifies reporting continuity, detects duplicate campaign-day entries, and rejects records with missing identifiers with explicit, fail-fast error messages. Derived performance indicators—Cost Per Acquisition ($\text{CPA} = \text{cost}/\text{conv}$), Click-Through Rate ($\text{CTR} = \text{clicks}/\text{impressions}$), Conversion Rate ($\text{CVR} = \text{conv}/\text{clicks}$), Cost Per Mille ($\text{CPM} = (\text{cost}/\text{impressions})\times 1000$), and Return on Ad Spend ($\text{ROAS} = \text{revenue}/\text{cost}$)—are computed using safeguarded zero-division rules that assign undefined (`NaN`) states rather than artificial zeros when denominators vanish. 

To eliminate self-contamination and forward-looking data leakage, each day $t$'s baseline is estimated strictly from historical observations within a causal lookback window $[t - W, t - 1]$, where $W \in \{21, 28, 35\}$ days (default $W = 28$ calendar days, exactly 4 full weekly cycles). Baseline central tendencies are calculated using day-of-week (DOW) stratified rolling medians, preserving cyclical weekend traffic depressions without parametric distortion. Historical dispersion is quantified using the Median Absolute Deviation ($\text{MAD} = \text{median}(|x - \text{median}(x)|)$), scaled to standard deviation equivalence via the normal consistency multiplier ($\hat{\sigma}_{\text{robust}} = 1.4826 \times \text{MAD}$). 

To protect low-volume campaigns from alert fatigue driven by discrete integer noise and small-sample ratio instability, an uncertainty floor is computed based on Poisson standard errors ($\sqrt{\max(\hat{\lambda}, 1.0)}$) for discrete counts and binomial proportion standard errors ($\sqrt{\hat{p}(1-\hat{p})/\max(N, 10)}$) for conversion and click rates. The effective uncertainty half-width is defined as $\text{Band} = \max(T \times \hat{\sigma}_{\text{robust}},\, \text{Floor})$, where $T$ is a configurable multiplier. Whenever downstream classification detects a confirmed operational incident, a feedback hook excludes the affected campaign-days from the rolling training pool for a freeze window of up to 14 calendar days, preventing slow or sustained anomalies from corrupting baseline norms. The resulting outputs are compiled into a standardized residual table containing actual values, expected baselines, robust scale metrics, statistical noise floors, and standardized robust $z$-scores ($\text{Robust\_Z} = (\text{Actual} - \text{Expected}) / \text{Effective\_Band}$) formatted to the Phase 0 team contract.
